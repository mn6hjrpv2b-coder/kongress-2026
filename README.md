# Сайт форума

Node.js 20+ и одна зависимость (nodemailer). Запуск: `npm ci && npm start`.

- Заявка с формы уходит письмом на `MAIL_TO` через SMTP (по умолчанию smtp.mail.ru:465).
- В Telegram уходит только сигнал «Новая заявка на сайте, проверьте почту» – без имени и телефона.
- Каждая заявка с отметкой и временем согласия на обработку ПДн дописывается строкой в `DATA_DIR/registrations.jsonl` (по умолчанию `./data`, в git не попадает).
- Если почта не ответила, заявка всё равно сохраняется на сервере, а сигнал в Telegram говорит, что письмо не ушло.
- `/health` – проверка, что сайт жив; `/setup?key=SETUP_SECRET` – узнать chat ID, пока он не задан.

Настройки – переменные окружения, пример в `deploy/primer-nastroek.txt`. Установка на сервер Timeweb Cloud – `deploy/timeweb-cloud-init.sh`, пошагово – в instrukciya.txt. Репозиторий может быть закрытым: сервер создаёт себе ключ доступа только на чтение (GitHub → Settings → Deploy keys) и показывает его открытую часть по адресу `/deploy-key.txt`.
